# Draft — Cirsium boninense existing genetic-data request

**Status: draft only; not sent.**

Purpose: recover and assess the existing 2025 genetic study of *Cirsium boninense* before commissioning duplicate new sequencing.

## Target study

Shinozaki T. et al. (2025), 「遺伝子情報によるオガサワラアザミの起源解明」, 日本植物分類学会第24回大会, p.69.

## Requested information / materials

- the full poster, extended abstract, or other method description if shareable;
- the molecular method actually used in the study;
- number of *C. boninense* individuals analysed;
- voucher, sample or locality identifiers for those individuals;
- whether flower-colour/taxon identity is explicitly linked to the sequenced individuals;
- raw-data or processed-data repository/accession identifiers, if deposited;
- if not deposited, whether a reusable sequence/genotype matrix or phylogenetic output can be shared;
- the relevant outgroup/comparator taxa and whether the analysis provides a species-level nuclear placement;
- any known restrictions on reuse or citation.

## Context to communicate

The immediate goal is not to reinterpret the authors' unpublished results. It is to determine whether the existing study already provides enough voucher-linked nuclear information to place *C. boninense* in a broader East Asian *Cirsium* phylogenomic comparison. If it does, the project should reuse or cite those data appropriately rather than generate redundant data.

For the current flower-colour transition-rate framework, one literature record alone is insufficient. Promotion requires at least two independent, taxonomically secure, flower-colour-linked nuclear samples or equivalent evidence of concordant placement. If the 2025 study does not meet that requirement, it can still guide the minimum additional sampling needed.

## Claim boundary

Until the authors/data source provides the method and exact data provenance, do not state that the study used MIG-seq, target capture, RAD-seq, WGS, or any other specific assay. Do not state that reusable sequence data are public merely because the study exists.
