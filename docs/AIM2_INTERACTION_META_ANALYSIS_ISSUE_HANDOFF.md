# Aim 2 interaction evidence-map handoff

Status: 2026-08-18

This is the execution checklist for the full census behind the bounded seed in `cirsium_interaction_evidence_seed_v1.csv`.

## Main goal

Complete only the literature work that can change the ancestry-resolved field design for head orientation, flower colour or involucre/phyllary/spine function.

## Tasks

1. Freeze dated GloBI, Mangal and Web of Life discovery derivatives with source identifiers.
2. Search primary literature by *Cirsium* species and interaction class.
3. Deduplicate database records and papers at the original-study level.
4. Separate visitor abundance, effective pollination, florivory, pre-dispersal seed predation and foliar herbivory.
5. Extract quantitative statistics into `data/templates/cirsium_interaction_effect_size_template_v1.csv` only from verified primary sources.
6. Recompute module gates and authorize pooling only when one harmonized outcome reaches >=5 independent studies and >=3 taxa.
7. Translate the result into exact Aim 2 field contrasts; do not create another doctoral Aim.

## Stop rule

Stop the literature expansion when additional records no longer change:

- which module is manipulated first;
- which interaction and fitness outcomes must be measured;
- which focal populations or controls are required;
- whether a formal pooled effect is identifiable.

A larger bibliography without a changed field or claim decision is not mainline work.
