# Orientation transition-regime H2 — linear geography residualization

## Question

Does the already-supported fixed transition-regime correspondence survive removal of the simplest taxon-level geographic gradients?

Fixed H2:

`U -> D` branch weighting should align with `BIO15 residual up + BIO1 residual down`, where each environmental axis is first residualized against taxon-centroid latitude and longitude.

No new predictor or environmental direction is introduced.

## Primary panel

Strict n>=10 East-Asian panel: 9 taxa, 5 U / 4 D, all 126 count-preserving state maps.

## Sensitivity

n>=5 East-Asian panel: 12 taxa, 7 U / 5 D, all 792 maps.

## Decision

The hypothesis is supported only if the strict n>=10 panel retains a positive composite on all six accepted topologies and an exact one-sided state-map fraction <=0.05. The n>=5 panel cannot rescue strict-panel failure.

## Boundary

This removes only linear latitude/longitude structure. It does not remove all geography, historical range, regional membership, ancestry, or unmeasured climate structure, and it is not a causal test of climate, adaptation or physiology.
