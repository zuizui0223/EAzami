## Purpose

This table prevents three shortcuts:

1. image phenotype → functional trait;
2. repeated phenotype → independent origin;
3. independent origin → adaptive convergence.

Each phenotype is therefore tracked through separate columns for measurement, candidate function, function evidence, focal validation, history, origin and convergence.

## Current trait classes

### Orientation

Current status: **candidate function calibrated + repeated phenotype history**.

- Azami provides a continuous orientation endpoint.
- External manipulations support effective-pollination and abiotic-protection pathways.
- No direct focal Japanese Cirsium manipulation yet licenses a functional/adaptive claim.
- Japan38: 20 resolved, ML minimum 6, UFBoot 4–6; exact branch localization remains weak.

### Phyllary posture

Current status: **protective-envelope candidate + robust repeated history**.

- Azami image geometry and authority-coded posture are related but not interchangeable.
- Pedicularis provides a nonhomologous protective-envelope analog, not a transported Cirsium effect.
- Japan38: 10 resolved and exactly 3 minimum changes across all 1000 UFBoot trees.
- JPN36 is the strongest current ancestry-aware manipulation target.

### Armature

Current status: **candidate morphology only**.

Azami measures projection/peak-density image geometry, but the mapping from those 2-D proxies to antagonist exclusion has not been directly validated. No trait-history or adaptive claim is licensed yet.

### Stickiness

Current status: **context-dependent function + robust repeated history**.

- Functional evidence has benefit, direct Cirsium null and cost directions; no universal defence sign is retained.
- After merged PR #124, Japan38 has 13 resolved concepts, ML minimum 5, root sticky, and exactly 5 minimum changes in all 1000 UFBoot trees.
- JPN15 neutralization is the primary causal necessity test; JPN06 is an external ancestry-matched sister comparator, not a substitute for within-species manipulation.

### Continuous colour

Current status: **candidate function + negative historical control**.

Colour has plausible pollinator and abiotic/pigment functions, but the global/high-depth lightness pattern does not replicate in the source-balanced Japan-local panel. It is therefore not promoted to a Japanese-radiation repeated-history result.

### Outline / continuous involucre architecture

Current status: **decomposed phenotype, function not yet validated**.

These metrics remain important because Azami shows that the head is multidimensional, but they cannot be labelled functional modules until a measurable performance mapping is independently established.

### Display quantity

Current status: **supported functional module outside the frozen 18D handoff**.

Cirsium literature supports context-dependent pollinator benefit and antagonist exposure. It remains a field/functional module rather than one of the current Japan38 repeated-history results.
