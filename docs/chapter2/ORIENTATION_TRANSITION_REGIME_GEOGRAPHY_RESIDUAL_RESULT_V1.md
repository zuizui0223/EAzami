Does the fixed East-Asian U→D transition-regime correspondence with `BIO15 up + BIO1 down` survive removal of the simplest linear geographic gradients?

BIO15 and BIO1 taxon centroids were separately residualized against latitude and longitude, then the same CTMC edge-transition × Brownian branch-shift statistic and exhaustive state-map null were reused without changing the hypothesis direction.

## Result

`transition_regime_concordance_persists_after_linear_geography_residualization`

Thus the fixed transition-regime signal is not removed by a simple linear latitude/longitude correction in the strict panel.

### n>=5 sensitivity

This secondary result is borderline and does not replace the strict-panel classification.

## Interpretation

The previously supported H1 is **not reducible to a simple north–south or east–west centroid gradient**. Combined with the earlier tests, three statements can now be separated:

1. the fixed U→D composite direction is not driven by one taxon (9/9 single deletions retain the direction);
2. it is not a universal Japan-only repeated rule (Japan-only exact rank 10/56 = 17.86%);
3. within the East-Asian panel, it remains exceptional after linear latitude/longitude residualization (5/126 = 3.97%).

The supported object is therefore a **distributed East-Asian lineage/regional transition-regime correspondence**, not a single-variable climate effect and not merely a linear geographic gradient.

This remains present-day niche correspondence. It does not identify transition-time climate, selection, adaptation, or the rain/wetting, radiation, thermal or pollination mechanism.
