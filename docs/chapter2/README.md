## Central result

> **A young *Cirsium* radiation repeatedly rebuilt the capitulum from components with unequal evolutionary histories and distinct plausible ecological interfaces. Orientation transitions track a present ecological regime, but that regime does not identify the tested coarse environmental trigger of the sole bounded historical origin event.**

### Historical assembly

- orientation: repeated, 4–6 minimum changes;
- phyllary posture: repeated, exactly 3;
- stickiness: repeated, exactly 5;
- paired depth ordering strongly favors phyllary deeper and stickiness shallower;
- complete central ordering occurs in 898/1000 topologies;
- 0/3 trait pairs show robust repeated shared transition localization.

`recurrent_mosaic_historical_reassembly`

not synchronized whole-head evolution.

Leading domains:

- orientation: abiotic reproductive exposure / timing;
