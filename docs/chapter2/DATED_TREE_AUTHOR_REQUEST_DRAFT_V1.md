# Draft request for machine-readable dated-tree outputs

**Status:** prepared, not sent

**Suggested subject:** Request for machine-readable phylogeny and RelTime outputs from Moreyra et al. (2025)

Dear Dr. Moreyra,

I am a graduate researcher studying the evolution of capitulum traits in Japanese and East-Asian *Cirsium*. Your 2025 paper, “A thorny tale: The origin and diversification of *Cirsium* (Compositae)” (Molecular Phylogenetics and Evolution 204:108285), provides the central temporal and biogeographic framework for my comparative analysis.

I am currently linking authority-backed capitulum states and continuous image-derived phenotypes to the Japanese radiation while explicitly propagating phylogenetic uncertainty. I would like to avoid extracting branch ages or topology from the published figures. Would it be possible to share any of the following machine-readable outputs from the analysis?

1. the best concatenated maximum-likelihood tree used as input to RelTime, preferably in Newick or Nexus format;
2. the RelTime time-calibrated tree, including node ages and confidence intervals, or the corresponding MEGA session/export;
3. the CP1–CP3 calibration configuration or a table identifying the constrained nodes by descendant tip labels;
4. the sample-label to BioSample/SRA accession and voucher crosswalk in a machine-readable table;
5. if available, the 350-locus concatenated supermatrix, partition file and/or post-orthology alignments;
6. if available, the BioGeoBEARS ancestral-area probabilities or fitted-object/node-state export used for Figure 3.

The immediate purpose is to map possible capitulum-transition branches to parent–child age intervals and ancestral-area uncertainty, then test prespecified palaeoclimate variables without assigning a single date to an unresolved transition. The data would be used with full citation to your article, and any additional reuse or acknowledgement conditions would be followed.

The public SRA data and Supplementary Table S1 are already being used for accession and voucher auditing, but I have not been able to locate a machine-readable dated tree or RelTime export in the public article, NCBI, research-portal or GitHub records. Even the first three items above would be sufficient for the primary chronological analysis.

Thank you very much for considering this request.

Sincerely,

ZHANG Ruiqi
