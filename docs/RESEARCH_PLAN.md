## Central problem

Chapter 2 asks:

> **How far can the present-day multivariate capitulum field constrain the histories that could have generated it?**

The dependency is explicit:

```text
Azami
present phenotypic field
        ↓
frozen empirical constraints
        ↓
EAzami
admissible / rejected generative-history classes
        ↓
Japan38 + population ancestry + functional experiments
realized-history and causal discrimination
```

Azami and EAzami are not parallel research pillars. Azami defines the empirical object to be explained. EAzami receives that frozen object and tests which history/mechanism classes can or cannot reproduce it.

## Current result

- The frozen Azami handoff contains 62 observational estimands.
- In the preregistered 14-family scalar-target screen, `NULL_COUPLED` is the robust structural-sufficiency winner.
- That same frozen winner reproduces the independently held-out replication-stable scale-specific support pattern in 0/64 draws.
- A post-heldout diagnostic shows strong directional improvement from `PROCESS_AMONG_ONLY_SHARED_COUPLED` (better than NULL in 22/24 paired draws), but no tested addition satisfies the preregistered adequacy rule.

Therefore the current conclusion is:

> **Scalar present-day geometry is historically non-identifying. Richer hierarchical constraints remove histories left admissible by scalar compression, but the currently tested generative families remain insufficient to identify one realized history.**

## Chapter 2 endpoint

The chapter does not need new biological sampling to establish the current paper claim. Its endpoint is a constrained history space, not a final adaptive explanation.

The next chapter/data layer uses nuclear population-genomic DNA + plastid haplotype + cytotype/genome-size information linked to standardized phenotype to distinguish standing ancestral variation, introgression/gene flow and lineage-specific origin. Functional manipulation and floral molecular work are further downstream.
