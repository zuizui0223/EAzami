The preregistered robust-leader rule selects **`NULL_COUPLED`**.

## What the result actually says

Within the frozen fourteen-family generator and the frozen class-balanced scalar distance, the **62 scored Azami values do not require explicit environment coefficients**. A generator with no environmental phenotype coefficients and a strongly shared contemporaneous residual component gives the best reduction of the scored target bundle.

This is a statement about structural sufficiency for the selected statistics. It is **not** evidence that climate has no biological effect on Cirsium capitula.

## Residual architecture

The residual contrast is defined as `score(COUPLED) - score(MODULAR)`, so positive values would favour modular residuals. The observed contrast is instead negative:

- primary median: **-5.856**; only **21.4%** of matched contrasts favour MODULAR, so **78.6% favour COUPLED**;
- replication sensitivity median: **-6.963**; **82.1% favour COUPLED**.

Thus the present global snapshot target bundle is more economically reproduced by a shared residual component than by independent module residuals.

This must **not** be relabelled as common evolutionary lability. `COUPLED` here is a cross-sectional residual covariance architecture and may absorb shared measurement, developmental, site or other latent structure. The independent Japan38 evolutionary-history result that a simple shared whole-capitulum lability model is not supported remains unchanged.

## Environmental-mode contrasts

The strongest consistent environmental comparison is between the two process placements:

- `PROCESS_AMONG_ONLY` beats `PROCESS_BOTH` in **89.1%** of primary matched contrasts and **93.8%** of replication-sensitivity contrasts.

So if process predictors are admitted into this minimal family, restricting their extra contribution to the among-taxon component is substantially better than forcing them to operate at both scales. This direction is compatible with the observed Azami scale asymmetry.

However:

- `PROCESS_BOTH` is worse than `CORE4` in the large majority of matched comparisons;
- `PROCESS_AMONG_ONLY` does not consistently beat `CORE4`;
- all explicit-environment families are decisively worse than `NULL_COUPLED` in the frozen total score.

Shared versus independent within/among coefficient architecture is not direction-consistent under the preregistered 0.75 rule.

## Critical inferential boundary revealed by the result

The 62-row fit uses:

- structure contrasts;
- raw multivariate block R2;
- coefficient-matrix cosine;
- raw incremental partial R2.

The Azami handoff also retains permutation P values, block-specific Q values and support states for the incremental environment tests, but the scoring contract explicitly excluded them to avoid adding a post hoc second score for the same estimand.

This matters because raw in-sample R2/partial-R2 can be nonzero under a response-null generator, especially at the among-taxon scale where the number of taxa is modest relative to the multivariate response and predictor dimensions. Therefore `NULL_COUPLED` winning the scalar-value score does **not** overturn the independent Azami result that some among-taxon process extensions were permutation-supported.

The discrepancy identifies a clean next falsification rather than a reason to retune this result:

> **Can the frozen `NULL_COUPLED` winner reproduce the held-out inferential-support pattern (permutation P/Q/support states) under the same nested tests?**

That check must remain a held-out validation. It cannot alter the v1 winner or retroactively change its scoring weights.

## Consequence for the doctoral synthesis

The current evidence no longer supports a simple sentence such as “global phenotype modularity plus process environment proves module-specific selection.” The layers instead separate:

1. **global snapshot:** raw covariance/environment target values are parsimoniously reducible by a coupled residual null model;
2. **global inferential environment layer:** some among-taxon process increments are permutation-supported and remain to be challenged by held-out winner validation;
3. **Japan38 evolutionary history:** orientation, phyllary and stickiness repeatedly change, while a simple shared whole-capitulum evolutionary-lability explanation is not supported;
4. **functional evidence:** different modules retain different candidate pollination, abiotic and antagonist functions;
5. **field causality:** JPN36 phyllary and JPN15/JPN06 stickiness designs remain the direct mechanism tests.

The productive hypothesis is therefore not “modularity is already demonstrated,” but whether **cross-sectional coupling can coexist with module-specific evolutionary transitions and function**, and which latent/causal processes separate those scales.

## Stop rule

Do not change v1 generator priors, target weights, distance scales, seeds or family membership to remove the `NULL_COUPLED` result. Any next test is explicitly held out and cannot replace this one-shot outcome.
