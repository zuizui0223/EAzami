# Moreyra et al. 2025 exact-tree recovery and reanalysis decision rules

## Preferred evidence order

1. authors' deposited final tree and retained-locus files;
2. publisher-linked supplementary archive;
3. recognized data repository record linked by DOI/title/authors;
4. author-provided versioned files with provenance;
5. EAzami reanalysis from public PRJNA957074 reads.

A figure-traced topology is not accepted as an exact final tree.

## Minimum deposited-artifact package

A recovered authors' package is considered sufficient for branch-length-aware flower-colour analysis only when it contains:

- a machine-readable final topology;
- branch lengths;
- tip labels linked to the sample table;
- node support or a documented support-free final tree;
- rooting/outgroup information;
- enough locus/filter metadata to identify which published analysis the tree represents.

## Reanalysis trigger

Begin a public-read reanalysis only after the following are documented:

- Supplementary Data 1 recovered and searched;
- conventional Elsevier `mmc` files enumerated;
- Crossref/DataCite/TreeBASE/Dryad/Mendeley/figshare/Zenodo searches completed;
- corresponding-author tree/locus request attempted or intentionally deferred with reason;
- public PRJNA957074 libraries and submitted names reconciled.

## Reanalysis outputs

A valid EAzami reconstruction must archive:

- input run/BioSample manifest and checksums;
- Compositae1061 target/reference version;
- HybPiper or equivalent extraction commands;
- paralog warnings and copy-selection rules;
- sample-by-locus occupancy;
- exact conservative and expanded locus lists;
- per-locus alignments and gene trees;
- concatenated topology;
- ASTRAL-family topology;
- plastid maternal topology where recovered;
- software versions, random seeds and logs;
- comparison to clades/topologies reported in the paper.

## Naming rule

Any reconstructed result must be labelled:

> EAzami reanalysis of public reads associated with Moreyra et al. 2025

It must not be described as the authors' deposited final tree unless the exact authors' artifact is recovered.

## Use in flower-colour analysis

- Run ancestral-state analyses across the authors' topology, EAzami reconstructed topologies and plausible conflict alternatives when available.
- Do not condition all conclusions on a single concatenated topology in a young, reticulate and partly polyploid radiation.
- Use sample/population-level flower-colour states only where tip identity is source backed.
- Report branches whose loss/regain interpretation changes across topology or coding alternatives.
